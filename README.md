# Distance between 2 points calculator

## Description
Calculates the distance between 2 points in a 2D plane using inputs and math library

## How to Run
1. Open the program file
2. Run the program
3. Enter respective values
4. See output

## Inputs needed
- x1
- x2
- y1
- y2

## Sample output
Enter x1: 6
Enter x2: 7
Enter y1: 10
Enter y2: -6
the distance between the points is 16.0312195418814
